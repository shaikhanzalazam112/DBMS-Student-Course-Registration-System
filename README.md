# Student Course Registration System

## Project Overview

The Student Course Registration System is a Database Management
Systems (DBMS) academic project designed to model the process of
student course registration and academic enrollment.

The project focuses on database design, entity relationships,
relational schema, and normalization up to Boyce-Codd Normal Form
(BCNF).

## Main Entities

The database design contains the following six core entities:

- Students
- Department
- Course
- Instructor
- Enrollment
- Section

## Database Design Topics

The project covers:

- Entity-Relationship (ER) Diagram
- Relational Schema
- First Normal Form (1NF)
- Second Normal Form (2NF)
- Third Normal Form (3NF)
- Boyce-Codd Normal Form (BCNF)
- Sample Data Tables

## Normalization

The database design is analyzed from UNF through BCNF.

According to the project report, all six tables satisfy:

- 1NF
- 2NF
- 3NF
- BCNF
